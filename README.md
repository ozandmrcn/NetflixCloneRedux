# NetflixCloneRedux
Welcome to the **NetflixCloneRedux** project! This is a feature-rich movie streaming interface inspired by Netflix. It utilizes Redux and Redux Thunk for state management and consumes The Movie Database (TMDB) API to dynamically fetch and display movie data.

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Activities/Bullseye.png" alt="Bullseye" width="25" height="25" /> Project Overview
NetflixCloneRedux allows users to explore movies by categories using a stylish slider. Each movie can be clicked to access a detailed page with information such as budget, revenue, trailer, and cast. Users can add or remove movies from their personal list. Trailers and cast members are shown in beautiful responsive sliders.

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Travel%20and%20places/Rocket.png" alt="Rocket" width="25" height="25" /> Features
- Home page with categorized movie sliders  
- Hero section with SplideJS movie slideshow  
- Movie detail pages with:
  - Budget and revenue info  
  - Video trailer previews (SplideJS + ReactPlayer)  
  - Cast with photo and name  
  - Add/remove to list buttons  
- Responsive UI with TailwindCSS  
- TMDB API integration  
- Environment variable for secure API key usage

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Wrench.png" alt="Wrench" width="25" height="25" /> Installation
Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/ozandmrcn/NetflixCloneRedux.git
cd NetflixCloneRedux

# Install dependencies
npm install

# Create a .env file and add your TMDB API key:
# in .env:
VITE_API_KEY=your_api_key_here

# Run the development server
npm run dev
```
